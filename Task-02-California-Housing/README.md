# Task 2: California Housing — Regularized Regression Comparison

Predict median house values from the California Housing dataset and compare
Ordinary Least Squares (OLS), Ridge (L2), and Lasso (L1) regression on RMSE,
MAE, and R².

## Problem Statement

Predict median house values using the California Housing dataset. Engineer
interaction features, impute missing values, handle multicollinearity, and
compare Ordinary Least Squares (OLS), Ridge (L2), and Lasso (L1) regression
models based on RMSE, MAE, and R² scores.

## Dataset

`data/raw/housing.csv` — the Kaggle "California Housing Prices" file:

```
longitude, latitude, housing_median_age, total_rooms, total_bedrooms,
population, households, median_income, median_house_value, ocean_proximity
```

20,640 rows × 10 columns. Two properties drive the workflow:

- `total_bedrooms` — **207 missing values**, imputed with the column median (435.0).
- `ocean_proximity` — **categorical**, 5 classes, one-hot encoded with the first
  level dropped.

## Workflow

1. Load and profile the dataset.
2. Impute the 207 missing `total_bedrooms` values with the median.
3. Exploratory analysis: feature distributions and a correlation heatmap.
4. Engineer four interaction features:
   `rooms_per_household`, `bedrooms_per_room`, `population_per_household`,
   `income_per_capita`.
5. Encode `ocean_proximity` with `OneHotEncoder(drop="first")`.
6. Train/test split (80/20, `random_state=42`) — done **before** encoding and
   feature selection so the test set stays untouched.
7. Handle multicollinearity: iterative VIF reduction on the training set only.
8. Standardize continuous variables (`StandardScaler`, fit on train only); the
   one-hot columns stay 0/1.
9. Fit OLS (`LinearRegression`) as the baseline.
10. Fit Ridge and Lasso over 15 log-spaced alphas with 5-fold `GridSearchCV`,
    scored by RMSE.
11. Compare RMSE / MAE / R² on the held-out test set.
12. Plot predicted vs actual values and residual distributions.
13. Save figures, metrics, and fitted models; reload and verify.

## Results

Split: 16,512 training / 4,128 test rows, `random_state=42`.

| Model | RMSE (USD) | MAE (USD) | R² |
| --- | --- | --- | --- |
| OLS (`LinearRegression`) | 69,777.73 | 48,694.66 | 0.6284 |
| Ridge (L2), alpha = 0.3162 | 69,782.00 | 48,698.50 | 0.6284 |
| Lasso (L1), alpha = 1.0000 | 69,777.24 | 48,695.26 | 0.6284 |

Lasso posts the lowest test RMSE, but it beats OLS by **$0.50** — far inside the
$749 cross-validation standard deviation, and the R² values agree only to five
decimal places. **Once multicollinearity is handled, regularization buys
essentially nothing on this dataset.** The tuned alphas are small (0.32 and
1.0), which is what a well-conditioned problem looks like. Ridge is marginally
*worse* than OLS: its best alpha adds a little bias without reducing variance
enough to pay for it.

## Multicollinearity

VIF was computed on the training set only; features above 10 were dropped
iteratively (highest first):

| Dropped feature | VIF |
| --- | --- |
| `total_bedrooms` | 49.88 |
| `latitude` | 20.35 |
| `households` | 19.70 |

All 13 remaining features sit below 8.4. Removing the raw counts also explains
why Lasso zeroes nothing: the strongly collinear columns are already gone and
the ratio features that replaced them are nearly orthogonal.

## Caveat

`median_house_value` is censored at the $500,000 ceiling (stored as 500,001);
992 rows (4.81%) sit on it. That ceiling, not model choice, is the dominant
source of the remaining ~$69.8k RMSE and is why R² stalls near 0.63.
